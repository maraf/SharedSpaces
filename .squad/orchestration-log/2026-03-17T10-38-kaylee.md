### 3. Quota Enforcement
- Quota calculated as: **sum of `FileSize` for all items in space + incoming file size**
- If quota exceeded, endpoint returns `400 BadRequest` with validation details
- Quota limits read from `Storage:MaxFilesPerSpace` (default: 50 MB)
