## Key Technical Decisions

1. **Aspire Packages Used:**
   - `Aspire.AppHost.Sdk/13.0.2` (current stable for .NET 10)
   - `Aspire.Hosting.NodeJs/9.5.2` (latest available; Aspire 13.x hosting packages not yet released)

2. **Orchestration Approach:**
   - Server: `AddProject<Projects.SharedSpaces_Server>("server")`
   - Client: `AddNpmApp("client", "../SharedSpaces.Client", "dev")`
   - Client wired to port 5173 via `WithHttpEndpoint(port: 5173, env: "PORT")`
   - Client sets `BROWSER=none` to prevent auto-opening
   - Client waits for server ready via `WaitFor(server)`
   - Server receives client URL via `Server__DefaultClientAppUrl` environment variable

3. **Design Philosophy:**
   - No ServiceDefaults project — minimal, single-file approach per user request
   - Enables one-command local dev startup: `dotnet run --project src/SharedSpaces.AppHost`
   - Developers can still opt for manual terminal approach if preferred
