## What Was Done

Implemented per-space upload quota backend with validation and enforcement.

### Core Changes

- **Domain Model:** Added `long? MaxUploadSize` to `Space` entity (nullable; null = server default)
- **Database:** EF migration `AddSpaceMaxUploadSize` with nullable INTEGER column
- **API Request/Response:** Extended `CreateSpaceRequest` with optional `MaxUploadSize`; added `MaxUploadSize` and `EffectiveMaxUploadSize` to `SpaceResponse`
- **Validation:** Create endpoint rejects quota ≤ 0 or > server default (100MB)
- **Enforcement:** Upload endpoint (`ItemEndpoints`) resolves per-space quota with fallback to server default

### Key Design Decision

- Nullable column distinguishes "not set" from "explicitly set to default"
- Server default acts as ceiling — prevents quotas exceeding storage capacity
- Resolution happens in two places: API response (for client display) and upload validation (for enforcement)
