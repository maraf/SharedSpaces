## Summary

Implemented `POST /v1/spaces/{sourceSpaceId}/items/{itemId}/transfer` endpoint to support copying and moving items between spaces with dual-token authorization, quota enforcement, file copying, and SignalR broadcasts.

## Changes Made

**Files:**
- `src/SharedSpaces.Server/Features/Items/ItemEndpoints.cs` — Added `TransferItem` endpoint (~250 lines)
- `src/SharedSpaces.Server/Features/Items/Models.cs` — Added `TransferItemRequest` class

**Key Implementation Details:**
- Dual-token authorization: source (Bearer header) + destination (request body)
- Server-generated destination item IDs (not reused from source)
- Serializable transactions with quota lock on destination space
- Stream-based file copying (no memory materialization)
- SignalR broadcasts: `ItemAdded` to destination, `ItemDeleted` to source (move only)
- Same-space transfers rejected (400 Bad Request)
