## Phase: Design Variants Ideation (Completed)

**Objective:** Propose 4 design variants for action button consolidation on mobile (#152).

**Output:** `.squad/decisions/inbox/wash-action-button-variants.md`

**Variants Proposed:**
1. **Kebab Menu (Three-Dot Overflow)** — Primary action visible + dropdown for secondary
2. **Swipe-to-Reveal Actions** — Swipe left to reveal all buttons
3. **Long-Press Context Menu** — Long-press to open modal menu
4. **Single Button + Bottom Sheet** — Single "Actions" button opens slide-up sheet

**Recommendation:** Variant 1 (Kebab Menu) — optimal balance of discoverability, space efficiency, and desktop compatibility.

**Complexity Analysis:**
- Variant 1: Medium
- Variant 2: High (gesture handling, accessibility concerns)
- Variant 3: Medium (long-press detection)
- Variant 4: Medium-High (bottom sheet component)

**Decision:** Kebab menu recommended for next phase implementation.
