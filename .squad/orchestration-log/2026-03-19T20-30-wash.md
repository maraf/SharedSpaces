## What Was Done

**Issue:** Uploader saw duplicate items due to a race condition between SignalR `ItemAdded` events and HTTP upload responses in the space-view component.

**Fix Applied:**
1. Added `private pendingItemIds = new Set<string>()` field to SpaceView component
2. Tracked item IDs during upload lifecycle:
   - `handleTextSubmit`: add itemId to set before API call, remove in finally
   - `uploadFiles`: add each itemId before its API call, remove after item is added
3. Updated `handleItemAdded`: skip if item in `pendingItemIds` OR already in `this.items`

**Implementation Pattern:**
```typescript
private pendingItemIds = new Set<string>();

private async handleTextSubmit(text: string) {
  const itemId = this.generateUUID();
  this.pendingItemIds.add(itemId);
  try {
    await this.api.uploadText(itemId, text);
    this.items.push(newItem);
  } finally {
    this.pendingItemIds.delete(itemId);
  }
}

private handleItemAdded(event: ItemAddedEvent) {
  if (this.pendingItemIds.has(event.itemId) || this.items.some(i => i.id === event.itemId)) {
    return;
  }
  this.items.push(event);
}
```
