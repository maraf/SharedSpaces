## What Was Built

Implemented the SignalR hub for real-time space updates (Issue #22):

### Features Delivered

1. **SpaceHub (`src/SharedSpaces.Server/Features/Hubs/SpaceHub.cs`)**
   - Routed at `/v1/hubs/space/{spaceId}`
   - JWT bearer authentication via `JwtBearerEvents.OnMessageReceived` (access_token query param)
   - `JoinSpace(Guid spaceId)` method with space_id claim validation
   - Per-space Groups for event isolation

2. **Event Broadcasting Integration**
   - `IHubContext<SpaceHub>` injected into `ItemEndpoints`
   - `ItemAdded` event broadcast on POST/PUT item
   - `ItemDeleted` event broadcast on DELETE item
   - Broadcast to `space:{spaceId}` group only

3. **CORS Configuration**
   - AllowAnyOrigin() fallback with `Server:DefaultClientAppUrl` override
   - AllowCredentials for WebSocket auth
   - AllowAnyHeader, AllowAnyMethod

4. **Service Registration**
   - `services.AddSignalR()` in `Program.cs`
   - JWT bearer middleware configured for SignalR token extraction

## Test Status

All changes integrate with existing test infrastructure. Zoe's 15 integration tests (squad/22-signalr-tests) validate the implementation.

## Technical Notes

- JWT token extraction from query string enables WebSocket authentication (standard ASP.NET Core SignalR pattern)
- SpaceHub validates space membership before adding to group, preventing cross-space subscriptions
- Event DTO validation matches test expectations (ItemAddedEvent, ItemDeletedEvent records)
