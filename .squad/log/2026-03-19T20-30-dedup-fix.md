## Problem

Uploader saw duplicate items in space-view due to race condition:
1. Client generates UUID, sends PUT request
2. Server saves, broadcasts SignalR `ItemAdded` to all clients, returns HTTP response
3. If SignalR event arrives before HTTP response: `handleItemAdded` adds item, then PUT handler also adds it → **DUPLICATE**

## Solution

**Wash (Frontend Dev):** Added `pendingItemIds: Set<string>` tracking in space-view.ts
- Track item IDs during upload lifecycle (add before API call, remove in finally)
- Skip SignalR dedup if item in pendingItemIds or already in items list
- Result: Lint ✅, Build ✅, Commit 3502e56

**Zoe (Tester):** Wrote 7 integration + unit tests
- Hybrid strategy: Integration tests for race condition, unit tests for simple logic
